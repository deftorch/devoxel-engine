# Devoxel Engine

WebGPU-based Voxel Engine.

## Fitur

- WebGPU Renderer
- Entity Component System (ECS)
- Standalone Voxel Editor

## Persyaratan

- Browser dengan dukungan WebGPU (misalnya Chrome/Edge versi terbaru)
- Node.js (jika ada build tools)

## Setup

1. Clone repositori ini.
2. Buka `index.html` atau `editor.html` (atau gunakan server lokal untuk menghindari isu CORS).
